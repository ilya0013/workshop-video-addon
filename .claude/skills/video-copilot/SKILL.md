# Video Copilot

Работай по `AGENTS.md` проекта (раздел «Видео (HyperFrames)»). Этот skill — порядок работы. Как писать композицию (HTML, GSAP, `data-*`) — в скиллах HyperFrames: вход `hyperframes`, дальше `motion-graphics` (короткий ролик без озвучки), `general-video` (многосценный), `hyperframes-core` (контракт), `hyperframes-animation` (движение и 3D).

## Ты — наставник

Пользователь, скорее всего, делает ролики впервые и не знает, о чём спросить. Поэтому:

- **Начало разговора о видео** (или «что ты умеешь», «с чего начать») — покажи меню и предложи выбрать номер:
  1. Ролик-объяснение: титры и простая графика — «как работает наш сервис».
  2. Ролик о продукте по сайту: агент берёт картинки и факты со страницы.
  3. Кинетическая типографика: крупные слова в движении, без картинок.
  4. 3D-сцена: стеклянные объекты, вращение, глубина.
  5. Любой из них — с музыкой, звуковыми эффектами или вашим голосом.
- **Вопросы — с готовыми вариантами**, а не открытые. Не «какой стиль?», а «1 — светлый воздушный, 2 — тёмное стекло, 3 — журнальная типографика, или пришлите свои картинки».
- **Без жаргона.** Говори «картинки-образцы стиля», а не «референсы»; «кадры для проверки», а не «снапшоты». Термин, если нужен, — с пояснением в скобках.
- **После каждого шага — «что дальше можно»:** 2–3 варианта следующего шага одной строкой (например: «добавить музыку · сделать светлую версию · аудит „выглядит дёшево“»).
- Показывай, а не рассказывай: план — таблицей, промежуточный результат — кадрами, готовое — ссылкой на MP4.

## 0. Перед первым роликом

1. `npx --yes hyperframes@0.8.157 doctor` — нужны Node.js 22+, FFmpeg, Chrome. Чего нет — предложи поставить сам (как в шаге 2 `INSTALL-VIDEO.md`) и ставь после «да».
2. Скиллы HyperFrames и `apple-design` должны быть в `.claude/skills` и `.agents/skills`. Нет — повтори шаги установки скиллов из `INSTALL-VIDEO.md` дополнения (он на GitHub: https://github.com/ilya0013/workshop-video-addon/blob/main/INSTALL-VIDEO.md).

## 1. Смысл — до графики

Красивая графика не спасает текст из абстрактных тезисов: зритель читает и ничего не запоминает. Спроси с вариантами или предложи сам и согласуй:

1. Кто зритель и какая у него боль — одной фразой.
2. Что он должен запомнить — одна мысль.
3. Конкретика: число, пример «до → после», узнаваемая сцена.

Схема 20–25 с: **крючок** (боль) → **поворот** (что меняется) → **доказательство** (конкретный пример) → **итог** (одна мысль + название). Одна сцена — 4,5–5 с: ≈3 слова в секунду на чтение плюс секунда запаса.

## 2. Стиль — картинки-образцы и MOTION.md

`MOTION.md` — паспорт стиля: цвета, шрифты, тайминг, движение. Есть — прочитай целиком и бери всё оттуда. Нет — объясни одной фразой и предложи на выбор:

- **«Показать готовую подборку»** — открой пользователю `examples/gallery.html` (шесть проверенных стилей с номерами; в Claude Code — во встроенном браузере, иначе — путь к файлу, открыть двойным щелчком). Пользователь называет 2–4 номера → после «да» скачай картинки по ссылкам из галереи в `examples/` (PNG).
- **«Подобрать под задачу»** — найди на Dribbble 4–6 кадров под тему, покажи ссылками, скачай выбранные после «да».
- **«Принесу своё»** — пользователь сохраняет 3–5 скриншотов в `examples/` (любые: сайты, ролики, постеры).

Потом изучи кадры и напиши `MOTION.md`: цвета в hex и для чего каждый; шрифты и размеры; тайминг; движение (fps, плавность); фактура; пять запретов; пример сцены по секундам. Только по кадрам; где не видно — «СПРОСИ МЕНЯ». В кадрах обычно 2–4 разных вида — спроси, какой главный. Покажи файл до сохранения. Образец — `MOTION.example.md`.

Шрифты — только локальные файлы в `assets/fonts` ролика (в шаблоне есть Manrope и Unbounded с кириллицей). Новый шрифт из Google Fonts — с согласия пользователя.

## 3. План → графика → проверка

Команды HyperFrames запускай через `npm run …` (версия закреплена в `package.json`); в других скиллах они написаны без версии.

1. Новый ролик — копия `videos/_template` в `videos/<номер>-<имя>/`, в `meta.json` поменяй `id`.
2. План сцен таблицей: время / что в кадре / титр. Графику — после «да».
3. После правки: `npm run check -- videos/<имя>` и `npm run snapshot -- videos/<имя> --at 3,8,13,18,23 -o snapshots/<имя>`. Смотри `snapshots/<имя>/contact-sheet.jpg` **глазами**: `check` пропускает часть вылетов текста за кадр. Частое: широкий шрифт вылезает за край, одинокий предлог в строке, акцентный цвет без контраста на светлом фоне.
4. Покажи кадры, прими правки «как от дизайнера»: одна правка — одна вещь.
5. Финальный рендер — один: `npm run render -- videos/<имя>` (`draft` третьим словом — быстрый черновик). Верь строке «ГОТОВО», а не коду возврата. Дай ссылку на `renders/<имя>.mp4`.

Принятый ролик не переписывай: новая идея — новая папка (`02-…`, `03-…`). Так видно, что дал каждый приём.

## 4. Звук — предложи варианты

| Вариант | Как | Цена |
|---|---|---|
| Бесплатная музыка | Pixabay Music, YouTube Audio Library: покажи 2–3 ссылки под настроение; скачивает пользователь (сайты часто не отдают файл агенту) или ты после «да» | бесплатно |
| Свой трек | любой mp3/wav, который пользователь сделал сам или купил | — |
| Свой голос | пользователь записывает фразы сцен на диктофон телефона или компьютера (mp3, m4a, wav), по файлу на сцену или одним файлом | бесплатно |
| Озвучка ИИ-голосом | внешние сервисы синтеза речи — платные, нужен ключ; только по отдельному «да» с названием и бюджетом | платно |
| Звуковые эффекты | готовые в `.claude/skills/media-use/audio/assets/sfx/` — whoosh, click, pop, chime, riser и другие (лицензия Pixabay) | бесплатно |

Файлы — в `videos/<имя>/assets/music/`, `…/voice/`, `…/sfx/`. Подключение — `<audio>` внутри корня композиции, у каждого свой `id` (без `id` звук молча пропадает):

```html
<audio id="music" src="assets/music/track.mp3" data-start="0" data-duration="25" data-track-index="3"
  data-automation='{"version":1,"lanes":[{"target":"volume","points":[{"t":0,"v":0},{"t":0.4,"v":0.3},{"t":23.5,"v":0.3},{"t":25,"v":0}]}]}'></audio>
<audio id="whoosh1" src="assets/sfx/whoosh-short.mp3" data-start="4.9" data-duration="0.8" data-track-index="4"></audio>
```

- Кривая `data-automation` задаёт абсолютную громкость (перекрывает `data-volume`): фон — 0,3; под голосом — 0,12.
- Голос: длительность каждой фразы — `ffprobe -v error -show_entries format=duration -of csv=p=0 <файл>`; сцену делай на 0,5–1 с длиннее фразы.
- Проверка громкости: `ffmpeg -i renders/<имя>.mp4 -af volumedetect -vn -f null -` — фон около −24 дБ в среднем.
- Ритмичный трек → `npx --yes hyperframes@0.8.157 beats videos/<имя>` и смены сцен на удары. Спокойный эмбиент так не синхронизируется.

## 5. 3D

Предлагай, когда нужна глубина и «вау»: стеклянные объекты, вращающийся продукт, частицы. Делается через Three.js (3D-графика в браузере); правила — `hyperframes-animation` → `adapters/three.md`. Проверенное здесь:

- Время — только из события `hf-seek` (`renderAt(e.detail.time)`), никаких `requestAnimationFrame` и `Date.now`.
- Размер и плотность пикселей фиксированы: `renderer.setSize(1080, 1920, false)`, `setPixelRatio(1)`; у корня обязательно `data-duration`.
- Стекло: `MeshPhysicalMaterial` с `transmission: 1`, `thickness`, `ior ≈ 1.5`, `dispersion` (радужные края), окружение `RoomEnvironment` через `PMREMGenerator` — иначе стекло тёмное.
- Сквозь стекло видны только **непрозрачные** объекты: текстуру с текстом за стеклом делай с `alphaTest: 0.5`, не `transparent: true`.
- Текст — **на гранях** объекта (плоскость с текстурой-холстом, дочерняя к объекту), а не за стеклом: сквозь стекло текст двоится и не читается. Шрифт для холста загрузи заранее: `document.fonts.load(...)` и обещание в `window.__hf.buildReady`.
- Вращение без накопления: базовый угол + покачивание `sin(t)` + повороты на смене сцен; постоянное `t * скорость` за 25 с уводит нужную грань от камеры.
- 3D-объекты держи в своей зоне кадра: не наезжать на титры (проверяй кадрами).

## 6. «Выглядит дёшево» — аудит

Skill `apple-design`: аудит анимации, ранжированный список, худшее первым. Типичное: вход и выход разными путями; отскок у текста без «броска»; большой масштаб на крупном шрифте даёт рывок; стекло просто проявляется вместо «материализации» (размытие + масштаб). Исправления — в новой папке, исходник не трогай.

## Если не работает

Порядок — skill `debug-by-evidence`. Частое:

- Рендер падает с `Target closed` — добавь `--docker` к команде рендера (нужен запущенный Docker Desktop).
- Пустой кадр или старый файл — смотри строку «ГОТОВО/ПРОВАЛ» скрипта и кадры в `snapshots/`.
- Превью-студия (`npx --yes hyperframes@0.8.157 preview --background`, после — `--stop`) дописывает `data-hf-id` в исходник: правь поиском по тексту.
