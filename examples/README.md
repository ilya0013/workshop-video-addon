# examples — кадры-референсы для MOTION.md

Положите сюда 3–5 скриншотов моушн-дизайна, который вам нравится (PNG или JPG). Агент соберёт по ним `MOTION.md` — правила стиля ваших роликов. Картинки чужие: в Git они не попадают (`.gitignore`).

Где брать:

- Dribbble — https://dribbble.com/search/motion-graphics (фильтр Animated)
- Pinterest — запросы `motion graphics inspiration`, `kinetic typography`, `premium ui animation`
- Animation Reference — https://animationreference.org/
