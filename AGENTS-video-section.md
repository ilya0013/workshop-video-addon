## Видео (HyperFrames)

Ролики в этом проекте делаются на HyperFrames 0.8.157: HTML + GSAP → MP4 локально, без облака и ключей. Порядок работы — skill `video-copilot`; как писать композицию — скиллы HyperFrames (вход `hyperframes`).

- **Смысл до графики.** Сначала зритель, одна мысль и конкретика, потом сцены: крючок → поворот → доказательство → итог. Сцена — 4,5–5 с.
- **Стиль.** Перед тем как проектировать или анимировать, прочитай `MOTION.md` целиком: цвета, шрифты, тайминг и движение берутся оттуда. Файл задаёт вид, а не масштаб замысла. Чего нет — спроси. Закончив, сверь кадры с `MOTION.md`. Нет файла — предложи собрать его из 3–5 кадров в `examples/`.
- **Структура.** Ролик — папка `videos/<номер>-<имя>/` (копия `videos/_template`); принятый ролик не переписывать, новая идея — новая папка. MP4 — в `renders/`, кадры проверки — в `snapshots/`.
- **Проверка.** `npm run check -- videos/<имя>`, `npm run snapshot -- videos/<имя> --at 3,8,13,18,23 -o snapshots/<имя>` — кадры смотреть глазами до рендера. Финальный рендер один: `npm run render -- videos/<имя>`, верить строке «ГОТОВО». Команды HyperFrames — через `npm run …`: там закреплена версия.
- **Контракт композиции:** у элемента с таймингом `class="clip"`, `data-start`, `data-duration`, `data-track-index`; один приостановленный таймлайн в `window.__timelines["<id>"]`; без `Math.random`, `Date.now`, сетевых запросов; смена содержимого — слоями и прозрачностью, не `.call()`; шрифты — локальные файлы.
- **Платное.** Озвучка, генерация музыки и картинок, облачный рендер, `publish` — только по отдельному «да» с названием сервиса и бюджетом.
