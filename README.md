# Видео-дополнение к Workshop Starter v0.1.1

Дополнение превращает проект на Workshop Starter в мастерскую коротких роликов: агент (Claude Code или Codex) делает вертикальные ролики 10–30 с на HyperFrames — со звуком и без, в вашем стиле — и сам проверяет готовый MP4.

## Пример

Вы пишете агенту: «Сделай ролик на 20 секунд: как наш сервис экономит час в день. Без звука». Агент спрашивает про зрителя и главную мысль, показывает план сцен таблицей, собирает ролик, показывает кадры, принимает правки и отдаёт `renders/01-…mp4` со строкой «ГОТОВО: 20.00 с · декодируется целиком».

## Возможности

- Ролик по шагам: смысл → стиль → план сцен → кадры-снапшоты → один финальный рендер.
- Свой стиль из 3–5 картинок-образцов: агент собирает `MOTION.md` — паспорт стиля; есть готовая галерея из шести стилей.
- Звук: бесплатная музыка, свои треки, свой голос, звуковые эффекты; тихий фон под голос.
- 3D: стеклянные объекты, вращение, глубина (Three.js).
- Агент-наставник: меню возможностей, вопросы с вариантами, подсказка следующего шага.
- Аудит «выглядит дёшево» скиллом `apple-design`: правила плавного движения в духе интерфейсов Apple.
- Рендер с проверкой: длительность и целостность файла, а не просто «команда завершилась».

## Установка

Нужны: проект на Workshop Starter и интернет на время установки. Node.js и FFmpeg агент проверит и поставит сам после вашего «да».

1. Откройте в агенте папку своего проекта на Workshop Starter. Нет проекта — сначала поставьте [Workshop Starter](https://github.com/ilya0013/workshop-starter).
2. Отправьте — агент сам скачает дополнение с GitHub и поставит его:

```text
Установи видео-дополнение в этот проект с GitHub:
скачай https://github.com/ilya0013/workshop-video-addon/releases/latest/download/workshop-video-addon.zip
во временную папку вне проекта, распакуй и установи по INSTALL-VIDEO.md из архива.
Глобальные настройки не меняй. В конце сделай тестовый ролик, покажи результат
и удали временную папку.
```

3. Перезапустите сессию агента — появятся новые скиллы (Claude Code — новая сессия, Codex — новый чат).

## Как это работает

| Файл | Зачем |
|---|---|
| `.claude/skills/video-copilot`, `.agents/skills/video-copilot` | порядок работы над роликом (Claude Code и Codex — одна и та же инструкция) |
| `AGENTS-video-section.md` | раздел «Видео» для `AGENTS.md` проекта: стиль, структура, проверка, платное |
| `videos/_template` | шаблон ролика 1080×1920 со шрифтами Unbounded и Manrope (кириллица) |
| `scripts/render.mjs` | рендер + сверка длительности + полный декод |
| `package.json` | команды `dev`, `check`, `snapshot`, `render` (HyperFrames 0.8.157) |
| `MOTION.example.md`, `examples/` | образец паспорта стиля, галерея стилей `gallery.html` и где брать картинки-образцы |
| `INSTALL-VIDEO.md` | пошаговая установка для агента |

Скиллы HyperFrames и `apple-design` в архив не входят: агент ставит их в проект командой `npx skills add` без глобальных настроек.

## Ограничения

- Версия HyperFrames закреплена: 0.8.157. Обновление — отдельным шагом.
- Рендер локальный. На части компьютеров Chrome падает при захвате кадров — тогда нужен Docker Desktop и флаг `--docker`.
- Озвучка ИИ-голосом, генерация музыки и картинок, облачный рендер — платные или тяжёлые; агент делает их только по вашему отдельному «да». Свой голос и бесплатная музыка — без ограничений.
- Музыку и референсы вы приносите сами: проверяйте лицензию трека (Pixabay Music, YouTube Audio Library — бесплатно).
- HyperFrames Studio (настольное приложение) для Windows пока не вышло; просмотр — превью в браузере (`npm run dev`).
