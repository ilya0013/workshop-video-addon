# Видео-дополнение к Workshop Starter — установка v0.1.1

Дополнение учит проект на Workshop Starter делать короткие ролики (10–30 с) на HyperFrames: со звуком и без, в своём стиле, с проверкой результата. Работает в Claude Code и Codex, Windows и macOS.

## Что сказать агенту

Откройте в агенте **папку своего проекта на Workshop Starter** (в её корне лежит `AGENTS.md`) и отправьте — агент сам скачает дополнение с GitHub:

```text
Установи видео-дополнение в этот проект с GitHub:
скачай https://github.com/ilya0013/workshop-video-addon/releases/latest/download/workshop-video-addon.zip
во временную папку вне проекта, распакуй и установи по INSTALL-VIDEO.md из архива.
Глобальные настройки не меняй. В конце сделай тестовый ролик, покажи результат
и удали временную папку.
```

## Порядок для агента

0. «Папка дополнения» ниже — временная папка вне проекта, куда ты распаковал архив (внутри — `workshop-video-addon`). Скачивание — по ссылке из промпта; в Codex это запрос в сеть, он может уйти на проверку. После шага 10 удали временную папку.
1. Проверь, что в корне текущего проекта есть `AGENTS.md` (это проект на Workshop Starter). Нет — назови, какую папку открыть, и остановись.
2. Проверь программы: `node --version` (нужен 22+) и `ffmpeg -version`. Пользователь, скорее всего, не работал с терминалом — **ставь недостающее сам, после его «да»**, и объясняй простыми словами, что и зачем:
   - Windows: `winget install --id OpenJS.NodeJS.LTS -e` и `winget install --id Gyan.FFmpeg -e` (может появиться окно «разрешить изменения» — пользователь нажимает «Да»).
   - macOS: `brew install node ffmpeg`. Нет `brew` — дай пользователю одну команду с https://brew.sh для приложения «Терминал» (она попросит пароль от компьютера; агенту пароль не нужен и не передаётся) и подожди.
   - После установки пользователь **перезапускает приложение агента** — иначе новые программы не видны. Новая сессия ничего не помнит: перед перезапуском удали временную папку и попроси пользователя после перезапуска отправить тот же промпт установки ещё раз — уже установленное ты просто пропустишь.
3. Скопируй из папки дополнения в проект, **не перезаписывая существующие файлы** (совпало имя — покажи разницу и спроси):
   - `.claude/skills/video-copilot/` и `.agents/skills/video-copilot/` (две одинаковые копии);
   - `videos/_template/` (шаблон ролика со шрифтами);
   - `scripts/render.mjs`;
   - `MOTION.example.md`, `examples/README.md`, `examples/gallery.html` (галерея стилей).
4. `package.json`: нет в проекте — скопируй из дополнения. Есть — добавь в `scripts` четыре команды `dev`, `check`, `snapshot`, `render` из `package.json` дополнения, остальное не трогай.
5. Допиши в конец `.gitignore` проекта строки из `gitignore-video.txt` (если их там ещё нет).
6. Допиши в `AGENTS.md` проекта раздел из `AGENTS-video-section.md` — перед разделом `## Проверка`, если раздела «Видео (HyperFrames)» ещё нет.
7. **Codex:** песочница проекта без сети, а рендеру нужен Chrome — команды `npx` и `npm run …` в шагах 7–8 и дальше запускай с запросом на выполнение вне песочницы.

   Поставь скиллы в проект (без `-g` — глобальные настройки не меняются):

   ```bash
   npx --yes skills@latest add heygen-com/hyperframes -s '*' -a claude-code -a codex --copy -y
   npx --yes skills@latest add emilkowalski/skills -s apple-design -a claude-code -a codex --copy -y
   ```

8. Проверка установки:

   ```bash
   npx --yes hyperframes@0.8.157 doctor
   ```

   Затем создай `videos/00-smoke` копией `videos/_template` (в `meta.json` — `"id": "00-smoke"`), выполни `npm run check -- videos/00-smoke` и `npm run render -- videos/00-smoke draft`. Успех — строка «ГОТОВО: renders/00-smoke.mp4 … 5.00 с · декодируется целиком» (на Windows путь с `\`). Покажи ссылку на файл.
9. Скажи пользователю: новые скиллы видны после перезапуска сессии агента (в Codex — новый чат).
10. Отчитайся коротко и простыми словами: что поставлено, результат проверки, ссылка на тестовый ролик. Затем покажи меню из skill `video-copilot` («Ты — наставник») и предложи выбрать номер. Дальше работай по этому skill.

## Если что-то пошло не так

- `npx` не находит пакет или висит — нужен интернет; в Codex — запуск вне песочницы (шаг 7).
- `ffmpeg` не найден сразу после установки — перезапустить приложение агента.
- Рендер падает с `Target closed` — запустить Docker Desktop и добавить `--docker`: `npx hyperframes@0.8.157 render videos/00-smoke --docker -o renders/00-smoke.mp4`.
- Откат: удалить скопированные папки и вернуть `AGENTS.md`, `.gitignore`, `package.json` через Git (`git checkout -- <файл>`) или из копии.
